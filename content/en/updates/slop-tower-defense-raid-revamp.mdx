## Slop Tower Defense Raid Revamp Status

The official Roblox experience page listed a Raid Revamp for September 25, 2026. Because the game is live and the event listing can change, treat the live game UI as the final source for whether the revamp is active, delayed, or still rolling out.

The official page also lists a new game mode for October 2, 2026. Players returning after the September update should check the event panel, update notes, and current rewards before following an older raid guide.

## What to Check After the Update

### Raid entry requirements

Look for changed win, level, team, or currency requirements. A requirement shown in an older video may no longer match the current build.

### Rewards and event currency

Record the reward names and amounts shown in the current raid panel before spending them. Limited-time currencies may be separate from normal Cash, Gems, or Stars.

### Unit roles

Re-test damage, splash, stun, slow, and economy roles after the patch. A tier list written before a raid rebalance is a starting point, not proof that a unit is still the best choice.

### Codes and compensation

Check the [current codes page](/codes/slop-tower-defense-codes) after a patch. Mini updates, server problems, milestones, and data changes are common reasons for new community-reported codes.

## Preparation Checklist

1. Claim available playtime and quest rewards.
2. Redeem the officially published `SLOP` code if it is still accepted.
3. Keep a balanced damage lineup instead of investing only in one role.
4. Save some currency for the current raid or event shop.
5. Recheck recipes and trade values in the live UI before committing rare units.
