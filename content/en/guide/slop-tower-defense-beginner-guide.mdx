## Slop Tower Defense Beginner Route

New players usually need a reliable first-win path more than a permanent tier list. Start with the current in-game rewards, build a small damage core, and save resources until you understand which units your active mode requires.

### 1. Claim visible lobby rewards

Check Playtime Rewards, quests, and any event panel shown in the current build before spending Cash or Gems. These rewards can change with updates, so use the values displayed in-game rather than an old guide.

### 2. Redeem the official starter code

The official Roblox experience currently lists `SLOP` for cash. Follow the [code redemption guide](/guide/slop-tower-defense-how-to-redeem-codes) and verify the result in the game UI.

### 3. Build a balanced starter team

Prioritize a dependable damage unit before filling every slot with economy or support units. A practical early roster should cover:

- single-target damage for strong enemies;
- splash or area damage for grouped waves;
- an economy or support role only after the first two needs are covered.

The exact best unit depends on the current summon pool and upgrade costs. Compare the live unit panel with the [units and summoning guide](/units/slop-tower-defense-units) instead of trusting an old fixed ranking.

### 4. Learn placement before chasing rarity

Place damage units near bends or long path sections when the map allows it, then upgrade a small number of useful units rather than spreading Cash across the whole roster. A lower-rarity unit with a better upgrade path can be more useful for first wins than an unupgraded rare pull.

### 5. Spend resources with a goal

Use Cash for the summon or upgrade that fills your current weakness. Save event currencies until you know which event units or crafts are available in the current build. The [crafting guide](/crafting/slop-tower-defense-crafting) explains how to review a recipe before committing materials.

### 6. Move to harder modes gradually

Clear the easiest available map first, then test one difficulty step at a time. Raids, seasonal events, and AFK systems can have separate requirements; check the [updates and events page](/updates/slop-tower-defense-updates) after each official patch.

## Beginner Mistakes to Avoid

- Spending every currency before checking the event and crafting screens.
- Treating a community tier list as official balance data.
- Building only farm units and having no early damage.
- Copying an expired code from a search result without testing it.
- Assuming an event date or map rule remains unchanged after a patch.
